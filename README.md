# Mis Gastos web

App full stack con JavaScript: registro y login, cada usuario con sus gastos, base de datos SQL y publicada online.

- **Frontend:** HTML, CSS y JavaScript con `fetch`.
- **Backend:** Node.js + Express 5, sesión con cookie firmada y contraseñas con `scrypt`.
- **Base de datos:** SQLite en la compu y [Turso](https://turso.tech) online (`@libsql/client`).
- **Publicada en:** [Render](https://render.com) (plan gratis: la primera visita puede tardar un minuto en despertar).

## Probarla en tu compu

```
npm install
npm run dev
```

Abrí http://localhost:4000.

Proyecto del libro **«FULL STACK con JavaScript, Node y Express»** de [Tienda del Estudiante](https://tiendadelestudiante.com).
